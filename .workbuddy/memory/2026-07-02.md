### GIF 工具箱
- 新增 `src/pages/GifTool.tsx` + `src/lib/gif-encode.ts`（纯JS GIF编码器）
- 安装依赖：gifuct-js
- 三个功能标签页：
  - **帧拆分**：上传GIF → 实时预览 + 单帧导航 + 单帧下载PNG + 全部帧ZIP打包
  - **视频转GIF**：上传视频 → 配置FPS(5-20)和最大宽度(160-640) → 画布逐帧提取 → GIF编码 → 预览和下载
  - **变速 & 倒放**：上传GIF → 变速滑块(0.25x-4x) + 倒放开关 → 重新编码 → 预览和下载
- GIF编码器基于八叉树颜色量化 + LZW压缩，纯JS实现
- 注册：查询工具 > GIF工具，图标 Film（vite build 成功）

- 监听 keydown/keyup（全 window）+ mousedown/mouseup（window）事件
- 在 `src/styles.css` 添加完整 Key Tester 样式
- 路由：`/key-tester`

### Bug修复 1：按键时页面滚动
- 事件监听改为 `{ capture: true, passive: false }` 并添加 `e.stopPropagation()`，防止按键触发页面默认滚动
- 移除自动滚动日志的 `useEffect`（`scrollIntoView`），改为静态日志——最新日志在顶部，无需滚动

### Bug修复 2：布局间隔问题
- 小键盘区改用 CSS Grid (`repeat(4, 1fr)`)，`NumpadAdd` / `NumpadEnter` 跨2行，`Numpad0` 跨2列
- 导航区改用 CSS Grid (`repeat(3, 1fr)`)，`ArrowUp` 定位第2列，消除空白行和空占位符
